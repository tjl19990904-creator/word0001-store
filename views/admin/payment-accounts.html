如何获取 Stripe 密钥？
1. 注册/登录 Stripe Dashboard
2. 左侧菜单 → Developers → API Keys
3. 复制 Publishable key（pk_ 开头）和 Secret key（sk_ 开头）
4. 完成账户激活后，测试密钥自动切换为正式密钥

Webhook 密钥可选，用于自动确认支付。如不填写，支付成功后需手动确认订单状态。

如何获取 Airwallex API 密钥？
1. 登录 Airwallex Dashboard
2. 左侧菜单 → Settings → API Keys
3. 复制 Client ID 和生成 API Key
4. 确保已开通「Payment」产品权限（收单功能）

Webhook 密钥可选，用于自动确认支付。如不填写，支付成功后需手动确认订单状态。
Airwallex 支持同币种结算，无需强制换汇。

如何配置 Cash App 在线支付？
Cash App 在线支付通过 Square Web Payments SDK 实现，客户可直接在网站完成支付。
1. 注册/登录 Square Developer Dashboard
2. 创建新应用，在 Credentials 页面获取 Application ID 和 Access Token
3. 在 Locations 页面获取 Location ID
4. 确保已启用 Cash App Pay 支付方式

如果在线支付无法使用，客户可手动通过此链接付款。
